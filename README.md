# 📖 DivinePages — Sacred Texts Library

A beautiful, modern web application for reading three great sacred texts of humanity:

- ✝️ **The Holy Bible** (King James Version)
- ☪️ **The Holy Quran** (English Translation)
- 🕉️ **Bhagavad Gita** (Classic Translation)

## ✨ Features

- 📚 **Chapter-based reading** with sidebar navigation
- 🌙 **Dark / Light mode** with localStorage persistence
- 🔍 **Search** within the currently selected book
- 🔖 **Bookmarks** — save and manage your reading progress
- 🔤 **Font size controls** (A-/A+) for comfortable reading
- ⌨️ **Keyboard navigation** — arrow keys for prev/next chapter
- 📱 **Fully responsive** — works beautifully on mobile
- 🖨️ **Print-friendly** styles
- 🚀 **Zero dependencies** — pure HTML, CSS, and JavaScript

## 🚀 Getting Started

Simply open `index.html` in any modern browser. No server or build tools needed!

```
git clone https://github.com/sanjitkc339-rgb/DivinePages.git
cd DivinePages
open index.html
```
